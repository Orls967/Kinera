# Visual Identity — KINERA

**Document ID:** `KIN-DOC-08-01`  
**Status:** COMPLETE  
**Last Updated:** 2026-11-16  

---

## 1. Purpose

Defines KINERA's **Premium Automotive Engineering Laboratory** visual identity (`KIN-3D-001`–`KIN-3D-003`), ensuring the UI and 3D stage read as a precision CAD cutaway & simulation laboratory rather than an arcade game or consumer dashboard.

## 2. Requirements

| Req ID | Requirement |
| :--- | :--- |
| **KIN-3D-001** | Visual presentation across UI and 3D viewport shall strictly follow the *Premium Automotive Engineering Laboratory* palette (graphite dark charcoal, titanium silver, electric cyan, deep blue, controlled amber). |
| **KIN-3D-002** | UI controls shall maintain technical minimalism and precision tabular typography (`font-variant-numeric: tabular-nums`) for live simulation telemetry. |
| **KIN-3D-003** | 3D lighting and materials shall differentiate structural chassis, brushed/cast alloys, copper/HV orange EV cabling, rubber tires, and active energy-flow vectors unambiguously. |

## 3. Core Visual Language

- **Environment & Surfaces:** Deep Graphite `#0E1116`, Charcoal Laboratory Panel `#151A22`, Precision Hairline Border `#262F3D`.
- **Metal & Structure Accents:** Titanium Silver `#C8D0DC`, Machined Aluminum `#8E99AA`, Deep Structural Blue `#1E3A5F`.
- **Engineering Telemetry & Flow Accents:**
  - **Electric Cyan `#00E5FF`:** Active energy flow, EV high-voltage / selected highlight, primary callouts.
  - **Deep Technical Blue `#2563EB`:** Chassis reference lines, baseline curves, comparative overlay B.
  - **Controlled Amber `#F59E0B`:** Mechanical torque intensity, thermal/load warnings, validity boundary alerts, mismatched-baseline flags.
  - **Critical Red `#EF4444`:** Friction-circle saturation (`Util > 1.0`), wheel lift, or error banner (strictly reserved for physical/validation limits).
- **Lighting Direction:** 3-point studio engineering rig (soft overhead area key, cool titanium rim light, subtle ground reflection grid with $0.5\text{ m}$ / $1.0\text{ m}$ metric calibration ticks).
